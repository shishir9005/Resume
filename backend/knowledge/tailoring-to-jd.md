# Tailoring a Resume to a Job Description

## Why tailoring matters
Recruiters search their ATS using keywords from the job description, and many systems rank applicants by how well the resume matches the posting. A generic resume can be well written and still rank low. Tailoring means adjusting the same honest content so it uses the posting's language and leads with the most relevant work.

## Finding the important keywords
Read the posting and mark: required skills (often under "Requirements" or "Must have"), preferred skills ("Nice to have", "Bonus"), tools and frameworks, and repeated phrases. Words that appear several times or in the job title are usually the most important. The ATS Resume Scorer's JD comparison lists matched keywords, missing keywords, and a skills gap to help with this step.

## Adding missing keywords honestly
For each missing keyword, ask: have I actually used this? If yes, add it where you used it, ideally inside a project or experience bullet, and also in the Skills section. If you have used something close (for example MySQL when the job asks for PostgreSQL), mention the related experience truthfully. If you have never used it, do not add it. A short project using the missing skill is a better fix than claiming it.

## Reordering for relevance
Move the most relevant project or job to the top of its section. Reorder bullets so the ones matching the posting come first. Adjust the summary line to name the target role, for example "Backend engineering intern candidate with Python and FastAPI experience".

## Semantic match versus keyword match
Modern systems also compare meaning, not only exact words. The ATS Resume Scorer combines exact keyword matching (60%) with semantic similarity (40%). Describing the same type of work the posting describes, in clear language, helps the semantic part even when exact keywords differ.
