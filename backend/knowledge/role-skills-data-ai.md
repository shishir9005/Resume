# Skills by Role: Data and AI

## Machine learning / AI engineering intern
Core skills: Python, NumPy, Pandas, scikit-learn, one deep learning framework (PyTorch is most common), model evaluation metrics, and experiment tracking. Strong signals: a project that goes beyond a notebook, such as a model served behind an API, a fine-tuned model with a clear evaluation, or a reproducible training pipeline. Good keywords: feature engineering, cross-validation, fine-tuning, transformers, model deployment, ONNX.

## LLM and generative AI roles
Increasingly common in China and globally. Core skills: prompt design, calling LLM APIs, retrieval-augmented generation (RAG), embeddings and vector search, tool calling or agents, and evaluating LLM output. Strong signals: a working RAG or agent application with an evaluation step (for example retrieval hit rate on a test set), cost and latency awareness, and guardrails. Good keywords: RAG, embeddings, vector database, LLM agent, function calling, LangChain or LlamaIndex (or a hand-written equivalent), evaluation.

## Data analyst intern
Core skills: SQL (joins, window functions, aggregation), Excel, Python with Pandas, data visualization (Tableau, Power BI, or Matplotlib), and basic statistics including A/B testing. Strong signals: an analysis project that ends in a business recommendation with numbers. Good keywords: dashboard, KPI, cohort analysis, data cleaning, hypothesis testing.

## Data engineering intern
Core skills: SQL, Python, ETL pipelines, a workflow tool (Airflow), big data basics (Spark, Hive, Hadoop, common at large Chinese companies), and data warehouse concepts. Strong signals: a pipeline that ingests, cleans, and loads data on a schedule with data quality checks.

## Showing evaluation, not just training
For any data or AI project, recruiters want to see how you measured success: accuracy, F1, RMSE, retrieval hit rate, or a business metric, plus a baseline to compare against. "Improved F1 from 0.71 (TF-IDF baseline) to 0.84 with a fine-tuned BERT model" is much stronger than "trained a BERT model".
