# Skills by Role: Software Engineering

## Backend engineering intern
Core skills recruiters look for: one main language (Python, Java, Go, or C++), REST API design, a web framework (FastAPI, Django, Flask, Spring Boot, or Gin), SQL databases (MySQL or PostgreSQL), caching with Redis, Git, Linux basics, and Docker. Strong signals: a deployed API with authentication, database migrations, tests, and a README. Good keywords: RESTful API, microservices, authentication, JWT, ORM, unit testing, CI/CD.

## Frontend engineering intern
Core skills: HTML, CSS, JavaScript and TypeScript, one framework (React or Vue; Vue is very common at Chinese companies), state management, HTTP and REST, responsive design, and browser developer tools. Strong signals: a live deployed site, performance improvements with numbers (Lighthouse score, load time), and reusable components. Good keywords: React Hooks, Vue 3, component library, Webpack or Vite, accessibility.

## Full-stack intern
Combine a frontend framework with a backend framework and a database, and show one end-to-end project that is deployed with authentication and persistent storage. Recruiters want to see you can own a feature from database to user interface.

## Mobile intern
Android (Kotlin, Jetpack), iOS (Swift, SwiftUI), or cross-platform (Flutter, React Native). Show a published app or a complete app with screenshots, API integration, and local storage.

## Fundamentals every software role checks
Data structures and algorithms, object-oriented design, basic operating systems and networking concepts (processes and threads, HTTP, TCP), and version control with Git. These are tested in coding interviews regardless of what the resume says, so keep practicing alongside project work.
